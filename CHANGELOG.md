# Changelog

All notable changes to this project will be documented here. The project
follows [Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-05-20

First tagged release. Covers Phase 1 to 4 of the original plan plus the
production self-host stack.

### Added

- **Memory**: typed memories (`working` / `session` / `fact` / `procedural`)
  with TTL sweep, hybrid BM25 + vector search, optional lineage and
  `include=embedding` projection.
- **Indexing**: GitHub repos (public via shallow clone, private via GitHub
  App installation tokens) and docs sites (native crawler plus optional
  Firecrawl) through a polling worker. Chunking is AST-aware with cAST-style
  parent/child links and per-chunk contextual prefixes generated by Claude
  Haiku (prompt caching enabled).
- **Retrieval**: `/v1/search` returns raw chunks, rendered markdown with
  citations and permalinks, or LLM-synthesized answers. Permalinks pin to
  the commit SHA captured at indexing. Reranking is optional via Voyage
  rerank-2.5 or a local `Xenova/bge-reranker-v2-m3` ONNX model.
- **Webhooks**: GitHub push events route through the `installation.id` and
  the workspace-scoped source's `githubInstallationId` config.
- **Cron**: 5-field expressions plus `@hourly/@daily/@weekly/@monthly/
  @yearly` shortcuts and `JAN`-`DEC`/`SUN`-`SAT` names.
- **MCP server**: stdio transport over `@modelcontextprotocol/sdk` with six
  tools (`source_search`, `source_index`, `source_list`, `memory_save`,
  `memory_search`, `memory_retrieve`).
- **CLI**: full coverage of the REST API (`auth`, `repos add`, `docs add`,
  `search`, `memory`, `sources`, `github installations`) plus `mnemis init`
  that wires Mnemis into Claude Code, Cursor, Windsurf and Zed configs.
- **SDK**: typed TypeScript client (`@mnemis/sdk`) bundled inside the CLI
  and exported standalone for third-party integrations, including SSE
  helpers for streaming job status.
- **Production self-host**: `docker/docker-compose.prod.yml` plus
  `Dockerfile.api`, `Dockerfile.worker` and `.env.prod.example` for a
  one-command stack with healthchecks and persistent volumes.
- **Evaluation harness**: `@mnemis/eval` ships nDCG/MRR/Recall metrics, a
  curated self-corpus dataset (`packages/eval/data/mnemis-self/`) and
  `bun run benchmark` which compares retrieval variants against a live
  API.

### Known limitations

- Cloud SaaS surface (Clerk, Stripe, landing page) is not yet in scope.
- Cross-encoder rerank requires either Voyage or the on-disk BGE model;
  there is no GPU-backed service yet.
- The benchmark dataset is intentionally small (10 queries on the Mnemis
  repo itself). Expand it before publishing public quality claims.
